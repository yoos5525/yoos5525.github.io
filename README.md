# ファイルアップロード/ダウンロード Webアプリ

Node.js + Express + multer を使ったシンプルなファイル共有アプリです。

## VSCode（Windows）でのセットアップ手順

1. **Node.jsをインストール**（未インストールの場合）
   https://nodejs.org/ からLTS版をダウンロードしてインストールしてください。

2. **VSCodeでこのフォルダを開く**
   - `ファイル` → `フォルダーを開く` で `file-upload-app` フォルダを選択

3. **VSCode内のターミナルを開く**
   - メニュー `ターミナル` → `新しいターミナル`（またはショートカット `Ctrl + @`）

4. **依存パッケージをインストール**
   ```
   npm install
   ```

5. **サーバーを起動**
   ```
   npm start
   ```
   ターミナルに `サーバー起動: http://localhost:3000` と表示されます。

6. **ブラウザでアクセス**
   http://localhost:3000 を開くと、アップロード画面が表示されます。

## 機能

- ドラッグ＆ドロップ、またはボタンからのファイル選択アップロード
- アップロード済みファイルの一覧表示（ファイル名・サイズ）
- ファイルのダウンロード
- ファイルの削除

## フォルダ構成

```
file-upload-app/
├── server.js         # Expressサーバー（API定義）
├── package.json      # 依存関係の定義
├── public/
│   └── index.html    # フロントエンド（画面）
└── uploads/          # アップロードされたファイルの保存先（自動生成）
```

## カスタマイズのヒント

- **ポート番号を変える**: `server.js` の `PORT` を変更、または環境変数 `PORT` を設定
- **アップロード容量の上限を設定したい場合**: `server.js` の `multer({ storage })` を
  `multer({ storage, limits: { fileSize: 10 * 1024 * 1024 } })` のように変更（例: 10MBまで）
- **社内ネットワークで他の端末からもアクセスさせたい場合**: `app.listen(PORT, ...)` を
  `app.listen(PORT, '0.0.0.0', ...)` に変更し、Windowsファイアウォールでポートを開放してください
